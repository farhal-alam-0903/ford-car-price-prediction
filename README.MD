# 🚗 Ford Car Price Prediction

A Machine Learning project that analyzes Ford car data and predicts car prices using **Linear Regression**. 

## 📌 Overview

This project follows a basic Machine Learning workflow to understand the factors related to Ford car prices and build a regression model for price prediction.

The project includes:

- Data Loading
- Data Exploration
- Statistical Analysis
- Missing Value Checking
- Exploratory Data Analysis (EDA)
- Data Visualization
- One-Hot Encoding
- Label Encoding
- Feature Scaling
- Train-Test Split
- Linear Regression
- Model Evaluation
